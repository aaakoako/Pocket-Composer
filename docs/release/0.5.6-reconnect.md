# Pocket Composer 0.5.6 · 可靠续接与草稿保护 / Reliable reconnection and draft protection

手机输入，电脑看清后插入。本版重点修复记住手机、断线续接、多标签草稿和插入重试，保留可选 Jev 参考侧栏、语气提示和现有图文工作流。

## 中文

- **记住这台手机更可靠**：手机确认凭据已保存后才显示已记住。电脑重启、短暂断网和同一浏览器再次扫码时，持有有效凭据的手机沿用原身份与权限；临时连接失败自动重试。
- **多标签不丢最后一句**：只有当前页面修改主稿。被接管页面的未保存文字另存，可在「最近」恢复；手机存储已满时保留页面内容供复制，重试保存成功后才继续切换。
- **失败可重试，已送达不重复贴**：没找到输入框且尚未执行插入时，可以再次点击。插入结果和回执持久保存，断线或电脑重启后仍能确认；结果未知或部分完成时不自动重贴。
- **设备操作各自独立**：记住、取消记住、昵称与权限只影响选定手机。写盘失败会回滚并提示，并发操作不会覆盖其他设备。
- **恢复与边界更清楚**：读取本地草稿失败不会用空稿覆盖；采用电脑稿前保全手机稿；图片恢复检查归属和授权。技术文字中的 PowerShell、cmd.exe 等按普通内容处理。
- **连接与升级更稳**：配对限流、本机管理接口与图片路径校验加强；退出超时后恢复可用状态；升级跳过可重建缓存并延长新版就绪等待。连接页大字号和窄窗口文字可换行。

### 下载与升级

Windows x64 用户下载 `DoubaoTypeless_0.5.6_win_x64_Setup.exe`；免安装使用便携 ZIP。文件名保留旧标识供更新器识别，产品名称为 Pocket Composer。安装包用于整套程序替换，保留旧数据，但不自动迁移旧框架数据。本次正式构建面向 Windows；macOS/Linux 仍是独立预览渠道。

已记住的手机需要使用同一浏览器和同一地址（含端口）。清除网站数据、换浏览器、换地址、主动撤销或凭据过期后仍需配对；无法从手机名字或 IP 恢复已经丢失的凭据。

## English

Speak or type on your phone, review on your desktop, then insert. This release improves remembered devices, reconnects, multi-tab drafts and safe insertion retries. Optional Jev reference bars, tone hints and the existing image/text workflow remain available.

- **Reliable remembered devices:** credentials are acknowledged only after durable phone storage. Valid credentials retain identity and permissions across desktop restarts and reconnects; transient failures retry automatically.
- **Protected drafts across tabs:** only the active page writes the main draft. Unsettled text from a paused tab is preserved in Recent. If storage is full, the page keeps its text available for copying and waits for a successful save before adopting another draft.
- **Explicit retries without duplicate delivery:** retry when no insertion step ran. Persisted results and receipts survive reconnects and restarts; unknown or partial delivery is never replayed automatically.
- **Per-device controls:** remembering, forgetting, nicknames and permissions affect the selected phone. Failed disk writes roll back, and concurrent changes no longer overwrite other devices.
- **Clearer recovery:** failed reads never replace a draft with an empty one. Adopting a desktop copy preserves the phone draft first; recovered images require ownership or approval. Technical words in user text remain ordinary content.
- **Connection and upgrade fixes:** rate-limited pairing, stricter local admin and asset boundaries, recovery after a timed-out quit, leaner upgrade backups, a longer readiness window, and wrapping labels in narrow or large-font windows.

### Installation and validation

Use the Windows x64 Setup executable or portable ZIP. Asset filenames retain the legacy identifier for updater compatibility; the product is Pocket Composer. Upgrades replace the complete application and preserve legacy data without automatically migrating the old framework's data. macOS/Linux remain a separate preview channel.

Remembered pairing belongs to the browser and origin, including its port. Clearing site data, changing browser/origin, revocation or expiry still requires pairing.
