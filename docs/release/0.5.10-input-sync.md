# Pocket Composer 0.5.10

- 修复手机和电脑「插入并复制」偶发失败：Windows 写入剪贴板后短暂读不出时会重试，不再误报内容被其他操作改变。持续不可读时保留原稿并显示可重试提示。
- 补齐输入法漏发事件时的文字同步。语音输入的后半段可自动同步到电脑，不再需要点插入才补上全文；插入和清空回执也会核对最新文字，避免清掉新输入的尾段。
- 明确未执行任何粘贴步骤的失败后，可以再次点击插入。已有粘贴步骤或结果不明时仍保留防重复保护。
- 完成插入后继续使用原有的清空、下一段和恢复流程。插入失败时保留稿件；程序不会自动发送消息。

0.5.9 日用修复构建已获用户「感觉可以了」反馈；正式安装包的验证记录见对应发行构建。此反馈不代表覆盖所有安卓浏览器、输入法和外部目标组合。

## English

- Retry transient Windows clipboard reads after writing, so Insert & copy no longer mistakes a temporary read failure for changed clipboard content. Persistent failures retain the draft and show a retry message.
- Reconcile text when an input method omits input events. Dictation tails sync without requiring an insertion click; insertion and clear receipts also check the latest text.
- Allow another explicit insertion click after a terminal failure with no paste steps. Keep duplicate protection when any step ran or the outcome is unknown.
- Preserve the existing next-draft and recovery flow after insertion, and retain drafts on failure. Insertion does not send messages automatically.
