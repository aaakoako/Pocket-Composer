# Pocket Composer 0.5.9

- 手机连接地址优先使用已连接的局域网网卡，避免默认出网路由被 Tailscale/VPN 接管时选错地址。连接页支持选择网卡和刷新网络地址，二维码与复制地址同步变化。
- 启动后及每 6 小时自动检查正式版本。发现更新时显示独立窗口；同次运行不会反复提示同一个版本。手动检查可在独立窗口查看结果、下载进度与错误，下载和安装仍需确认。
- 安装后创建桌面、开始菜单的 Pocket Composer 快捷方式；完成页默认勾选打开程序。卸载删除对应入口并保留用户数据。

验证记录以本版本对应的构建产物为准。实体手机经 Tailscale 或局域网连接、用户日用电脑的窗口焦点行为仍需实际使用确认。
