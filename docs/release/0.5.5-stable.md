# Pocket Composer 0.5.5 · 输入参考侧栏 / Reference sidebar

## 中文

0.5.5 首次作为 Windows 正式版发布。此前的 `preview-0.5.5` 与 Mac/Linux 包为体验版，不能等同于正式更新。

- **Jev 分段侧栏**：正文右侧显示目标、信息、上下文、结果四个维度，用短标签和音量条式分段呈现。可辨识、有歧义、依赖上文、暂无法判断分别显示，不伪造成功率百分比。
- **输入仍是主角**：Jev 默认关闭，关闭后侧栏完全收起；检查中保留布局并清除旧稿结果，避免侧栏反复挤压正文。
- **特色保留**：情绪图标、愤怒火焰动效、语音说明、完整参考详情均保留；不会强制用户补充提示词。
- **布局与焦点**：修正侧栏加入后的正文宽高计算，检查普通和大字体布局；修正 Pocket Composer 改名后的自身窗口识别。
- **原有流程**：手机文字、图片、白板、逐图后接文字、清空与恢复继续保留。正常插入不自动发送 Enter。

安装版与便携版都需使用完整包。升级保留工作区；旧版更新入口不再维护，可从本发布页手动下载安装包。模型分析可选，核心功能不需要 API Key。

本次正式安装包为 Windows x64。macOS / Linux 继续提供独立体验版，其系统权限、Wayland 与目标应用兼容性限制见 [跨平台说明](CROSS_PLATFORM.md)。参考只分析当前文字，不读取目标 Agent 的历史结果；分段是状态提示，不是模型准确率或任务完成率。

## English

This is the first stable Windows release of 0.5.5. Earlier `preview-0.5.5` and macOS/Linux packages were experimental releases.

- **Segmented Jev sidebar:** four labeled reference bars beside the draft—goal, information, context and outcome. Clear, ambiguous, context-dependent and unknown states remain distinct. No invented success-rate percentages.
- **Input first:** Jev stays off by default. Disabling it removes the sidebar; pending checks preserve the layout while clearing the previous draft's judgments.
- **Tone retained:** emotion icons, the anger flame effect, optional voice note and expanded details remain available. No mandatory prompt coaching.
- **Layout and focus fixes:** body sizing accounts for the sidebar; normal and large fonts are checked. Renamed Pocket Composer windows are correctly excluded as external paste targets.
- Text, images, whiteboards, image-then-text insertion and draft recovery remain available. Normal insertion does not send Enter.

Use the complete installer or portable archive. Keep the workspace when updating; legacy update entry points are no longer maintained, so download manually if necessary. Optional model features require your own provider configuration; core input does not.

Stable packages are for Windows x64. macOS/Linux remain separate previews; see [platform limitations](CROSS_PLATFORM.md). References cover the current text only, not target-agent history. Segments indicate categories, not accuracy or task-completion rates.
