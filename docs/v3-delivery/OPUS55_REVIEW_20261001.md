# 0.5.6 Opus 实现与 Codex 独立复核

本轮基于 `e5604f832e7a58bff5e57166bd5cd0b8aa7764e9`，由 Cursor 的 **Claude Opus 5.5 300K High** 实现，Codex 独立审查、复现和验收。经过三轮实现与复核，源码审查通过；正式发布与实机验收尚未完成。

## 已解决的问题

- 记住手机与续接：凭据保存确认、同设备身份、过期或撤销、失败回滚、多个设备的独立授权，以及 Qt/HTTP 同时修改信任记录时的覆盖。
- 手机草稿：读取失败不会空写覆盖；同一浏览器多标签页只有当前页写主稿；切换前尚未保存的文字及编辑内容保留为可恢复副本；可以明确采用电脑镜像。
- 插入：技术术语不再被误判为按键脚本；没有执行任何步骤时允许再次点击；已经投递或结果不确定的意图跨重启去重；回执先保存再发送。
- 图片、连接与安全：新身份重新上传本地原图；缺少原图时由电脑批准取回；限制素材路径及设备归属、管理接口来源和短码尝试；增加连接心跳。
- 桌面与升级：退出失败恢复队列及热键；练习框不覆盖手机稿；截图选择当前有效设备；升级备份排除下载缓存；设备控制分开显示，大字号版本说明换行。

Jev 仍是可选功能，情绪与火焰动效保留。主路径仍为图片后接文字，插入和重连不会自动按 Enter。

## 独立发现与关闭

Codex 第一轮独立用例为 19 通过、1 失败，随后另复现两处竞态。Opus 补修后 24 项独立用例通过。继续核对信任写入时，又复现两次“记住”成功却只保存一台设备，第三轮补修关闭该问题。

最终 **25 项 Codex 独立用例全部通过**，覆盖原审查故障、普通与技术词正文、失败重试、结果不确定时去重、重启后的去重与安全重试、本地读故障、普通 HTTP 能力、信任写盘故障及并发、跨设备素材隔离、短码限流、退出恢复、截图接收者和升级备份。
